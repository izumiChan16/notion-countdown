# PRD - Notion 倒计时 Widget

## 项目概述

一个轻量级的倒计时页面应用，可部署在 Vercel 上，通过嵌入 URL 的方式在 Notion 中使用。

## 核心功能

### 1. 配置页面
用户通过配置页面生成个性化的倒计时 Widget URL。

#### 配置项：
- **结束日期**：用户选择倒计时的目标日期时间
- **精度单位**：选择显示精度（天/小时/分钟/秒）
- **标题**：可选，是否显示标题及标题内容
- **主题模式**：是否跟随系统主题（浅色/深色/自动）
- **样式选择**：提供多种预设样式供选择

#### 输出：
- 生成带参数的 URL，格式如：`/widget?end=2024-12-31T23:59:59&unit=days&title=考试倒计时&theme=auto&style=minimal`

### 2. 倒计时展示页面
根据 URL 参数渲染对应的倒计时 Widget。

#### 展示内容：
- 标题（如果配置）
- 剩余时间（根据精度单位显示）
- 响应式布局，适配 Notion 嵌入尺寸
- 主题适配（根据配置）

## 技术栈建议

- **框架**：Next.js（适合 Vercel 部署）
- **样式**：Tailwind CSS（轻量快速）
- **部署**：Vercel

## 用户流程

1. 访问配置页面
2. 填写配置信息
3. 点击生成，获得 Widget URL
4. 复制 URL 到 Notion 的 Embed 块中
5. 倒计时自动显示并更新
